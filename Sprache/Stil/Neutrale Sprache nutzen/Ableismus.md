# Ableismus

## Ableismus

Ableismus ist die Diskriminierung aufgrund körperlicher, geistiger oder psychischer Fähigkeiten.  
Sprache spielt dabei eine zentrale Rolle, zum Beispiel durch:

- Beleidigungen, die aus Diagnosen stammen (z. B. „spastisch“, „behindert“ als Schimpfwort)
- Verharmlosung oder Romantisierung von Behinderungen („trotz seiner Behinderung…“)
- Klischees, Überhöhung („sie ist ein echtes Vorbild“)
- Redewendungen, die Defizite betonen („blind vor Wut“, „taub für Kritik“)

### **Beispiele: Ableistische Redewendungen und Alternativen**

| **Ableistische Formulierung** | **Problem / Ursprung** | **Empfehlung / Alternative** |
| --- | --- | --- |
| „taub für Kritik sein“ | Verallgemeinerung, abwertend | „Reagiert nicht auf Kritik“, „ignoriert sie“ |
| „Blind vor Liebe / Wut“ | Stereotyp, metaphorische Einschränkung | „Übersieht alles“, „verliert den Überblick“ |
| „An den Rollstuhl gefesselt“ | Drama, machtlos wirkend | „benutzt einen Rollstuhl“ |
| „Trotz seiner Behinderung…“ | Romantisierung, Überraschung über Leistung | Besser: Fokus auf Person und Leistung |
| „Sitzt im Rolli“ | Verniedlichend, umgangssprachlich | „Nutzt einen Rollstuhl“ |
| „Autist/in“ als Etikett | Reduziert Person auf Diagnose | „Person mit Autismus“ |
| „Ein Opfer von…“ | Passiv, defizit-orientiert | „lebt mit…“, „ist betroffen von…“ |
| „Er ist wahnsinnig nett“ | Psych. Erkrankungen als Alltagsmetapher | „sehr nett“, „besonders freundlich“ |
| „Ich krieg die Krise“ | Verharmlost echte psychische Krisen | „Ich bin gestresst“, „Ich bin überfordert“ |
