# Adjektive

### **Probleme mit Adjektiven:**

- Oft sagen sie wenig Konkretes aus
- Sie können den Text verwässern oder überladen.

Adjektive sind oft Platzhalter für fehlende Details.  
Wir hinterfragen sie kritisch und ersetzen sie durch konkrete Informationen. 

### **Was tun?**

- Inhaltlich prüfen:  
Was genau bedeutet „wichtig“? Warum „interessant“?
- Weglassen oder ersetzen:  
Statt „ein wichtiges Argument“ lieber „ein Argument, das zeigt…“
- Genauer beschreiben:  
Statt „schön“ lieber „klar strukturiert“ oder „anschaulich“

### **Beispiele**

| **Mit Adjektiv** | **Ohne Adjektiv bzw. genauer** |
| --- | --- |
| Das ist ein wichtiges Ergebnis. | Das Ergebnis zeigt, dass… |
| Sie hat eine interessante Idee. | Ihre Idee verbessert die Effizienz. |
| Ein gutes Beispiel. | Ein Beispiel, das den Ablauf verdeutlicht. |
| Das Projekt ist erfolgreich. | Das Projekt hat die Ziele erreicht. |
