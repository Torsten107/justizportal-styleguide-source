# Füllwörter

Wir verzichten auf Füllwörter, die keinen inhaltlichen Mehrwert bieten. Sätze werden so unnötig lang und kompliziert. 

> Lies den Satz ohne das Füllwort. Ändert sich der Sinn des Satzes? Wenn nicht, kann das Wort weggelassen werden. 

### **Häufige Füllwörter**

| **Füllwort** | **Funktion** | **Besser weglassen oder ersetzen durch** |
| --- | --- | --- |
| halt | Verstärkung, Zustimmung | – (meist überflüssig) |
| eben | Bestätigung, Zustimmung | – (meist überflüssig) |
| also | Überleitung, Betonung | „daher“, „demnach“, „folglich“ |
| irgendwie | Unklarheit, Abschwächung | konkreter ausdrücken |
| quasi | Vergleich, bildhafte Sprache | „vergleichbar mit …“ |
| eigentlich | Relativierung, Zweifel | direkt ausdrücken oder weglassen |
| wirklich | Verstärkung, Emotionalität | „sehr“, „besonders“ |
| vielleicht | Abschwächung, Unsicherheit | „eventuell“, „möglicherweise“ |
| sozusagen | Veranschaulichung | „bildlich gesprochen“, oder weglassen |
| übrigens | Zusatzinformation | „außerdem“, „zusätzlich“ |
| echt | Emotionale Verstärkung | „sehr“, „besonders“ |
| total | Starke Betonung | „sehr“, „äußerst“ |
| voll | Verstärkung | „stark“, „deutlich“ |
| richtig | Betonung | „sehr“, „extrem“ |
